# Portfolio wording and publishing guide

## Project description

SkyFlow is a synthetic airline DataOps platform built with Python, SQL, BigQuery, Pub/Sub and Terraform. It combines batch transformations, event streaming, data-quality gates and operational monitoring, with GitHub Actions checks and read-only AI-assisted diagnostic explanations through Abacus RouteLLM.

## CV bullet

Built an airline DataOps portfolio project with batch and streaming pipelines, BigQuery modelling, Pub/Sub ingestion, Terraform adoption of existing resources, automated tests, CI checks and AI-assisted operational diagnostics.

## LinkedIn post draft

Built SkyFlow, a synthetic airline DataOps project combining Python, BigQuery, Pub/Sub and Terraform.

The project includes batch and streaming pipelines, data-quality checks, operational monitoring, automated tests and GitHub Actions. Abacus RouteLLM adds read-only explanations of diagnostic findings for human review.

A key learning: reliable AI diagnostics depend on clear evidence and explicit limitations. The model suggests checks; it does not repair infrastructure.

Code: https://github.com/rishijay-k/skyflow-airline-dataops

## Showcase

1. Review the README and latest Actions result on GitHub.
2. Record the walkthrough in demo.md. No video has yet been produced by this repository preparation.
3. Add the repository to your LinkedIn Featured section and Projects section. Use the description above and state that the data is synthetic.
4. Attach the demo or architecture screenshot to the post. Publishing the LinkedIn post is a separate user action.

Avoid claims of airline affiliation, production deployment, exactly-once delivery, automatic remediation, proven business savings or a fully autonomous agent. No such claims have been established by this project.
